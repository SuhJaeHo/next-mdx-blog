# Chrome-like Group Tabs

Inspired by Chrome-style group tabs, I designed an interactive workspace where documents can be arranged and compared freely.

## Feature Implementation List

<ul className="overview-feature-list">
  <li><strong>Chrome-like group tab interactions</strong><span>Implemented tab reordering, splitting into independent panels, and merging them back together with Vanilla DOM APIs</span></li>
  <li><strong>Resizing implementation</strong><span>When a tab or group is dragged outside the panel and dropped, it resizes to half of the target area, and double-clicking the group header toggles between fullscreen and the previous size</span></li>
  <li><strong>NPM packaging</strong><span>Separated the Chrome-like tab resizing UI into an independent package and published it to NPM</span></li>
  <li><strong>MDX-based content rendering</strong><span>Serialized MDX content with next-mdx-remote and rendered tab-specific document content with GFM and code highlighting applied</span></li>
</ul>

## Motivation for Building This Portfolio

I thought it would be useful to use Chrome-style group tab interactions to provide a format where freely written posts can be separated, merged, or viewed together at the same time. I built this as my own portfolio, and I also plan to use the format as a blog for recording and organizing what I learn.
