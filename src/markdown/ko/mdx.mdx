# MDX

MDX는 JSX 문법을 사용할 수 있도록 확장된 Markdown입니다. 글, Markdown 구조, JavaScript 표현식, 컴포넌트를 하나의 문서 처리 과정에서 함께 다룰 수 있습니다.

## 컴파일 과정

<div className="code-explanation-list">
  <div><strong>Markdown과 MDX 문법을 파싱해 Abstract Syntax Tree로 변환</strong><span>Markdown 노드와 MDX 전용 노드를 Markdown 추상 구문 트리로 표현합니다.</span></div>
  <div><strong>remark 플러그인 실행</strong><span>remark 플러그인은 mdast를 검사하거나 변환합니다. remark-gfm은 표와 작업 목록 등 GitHub Flavored Markdown 문법을 지원합니다.</span></div>
  <div><strong>Markdown AST를 HTML AST로 변환</strong><span>Markdown AST를 HTML AST로 변환하며, MDX의 JSX와 표현식은 이후 컴파일 단계에서 처리할 수 있도록 보존합니다.</span></div>
  <div><strong>rehype 플러그인 실행</strong><span>rehype 플러그인은 hast를 검사하거나 변환합니다. 이 포트폴리오는 rehype-prism-plus로 코드 블록에 구문 강조 정보를 추가합니다.</span></div>
</div>

## MDX 렌더링 과정

```ts
import { serialize } from "next-mdx-remote/serialize";
import rehypePrism from "rehype-prism-plus";
import remarkGfm from "remark-gfm";

const source = await serialize(fileContent, {
  mdxOptions: {
    remarkPlugins: [remarkGfm],
    rehypePlugins: [rehypePrism],
    format: "mdx",
  },
});
```

<div className="code-explanation-list">
  <div><strong>MDX 파일 직렬화</strong><span>정적 생성 과정에서 MDX 파일을 읽고 serialize로 직렬화합니다.</span></div>
</div>

```tsx
import { MDXRemote } from "next-mdx-remote";

const components = { pre: CodeBlock };

export function CustomMDX({ source }) {
  return <MDXRemote {...source} components={components} />;
}
```
