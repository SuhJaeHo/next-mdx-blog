# 직무경력

## 서재호 · 프론트엔드 엔지니어

고빈도 실시간 데이터와 Web3 트랜잭션 환경에서 운영 이슈를 스스로 정의하고 끝까지 해결하는 프론트엔드 엔지니어입니다. 약 4년간 블록체인 기반 웹 서비스와 WebView 애플리케이션을 개발하며 설계부터 출시와 운영까지 경험했습니다.

## 기술

- **언어** TypeScript, JavaScript, Python
- **프론트엔드** React, Next.js, Zustand, Redux Toolkit, TanStack Query
- **Web3** Wagmi, Ethers.js, Viem, WalletConnect, Reown AppKit
- **실시간 처리 및 시각화** WebSocket, TradingView, Canvas API, Rive
- **UI 및 스타일링** Tailwind CSS, Emotion, MUI, Framer Motion
- **도구 및 인프라** Jira, Confluence, Slack, Figma, GitHub Actions

## [넥써쓰](https://www.homepage.nexus/) · 프론트엔드 개발

**2025.02 – 2026.05**

### Cross Public Sale

- 일주일 안에 프로젝트 셋업, 디자인 요구사항, 지갑 연동, RPC, KYC, 컨트랙트 호출 로직 구현
- 퍼블릭 RPC Rate Limit으로 발생한 조회 지연을 분석하고 JWT 인증 기반 프라이빗 RPC로 전환
- 약 **200억 원 규모의 Public Sale을 중대한 장애 없이 완료**
- RPC 전환 이후 데이터 조회 지연 0건

### CrossX · WebView 기반 하이브리드 지갑

- RN WebView 메시지 통신을 Promise 기반 함수로 표준화한 웹–네이티브 브리지 설계
- RN 브리지를 TanStack Query의 QueryFn과 호환되도록 설계해 브리지 통신을 서버 API와 동일한 비동기 상태 관리 모델로 통합
- 단일 라우트 SPA에 가상 히스토리 스택을 설계하여 Android 하드웨어 뒤로가기와 화면별 상태 연동
- 드로어의 드래그 진행률에 따라 현재·이전 화면 위치를 동기화해 네이티브 수준의 화면 전환 제스처 구현
- iOS·Android 양대 마켓 출시, **누적 다운로드 10만 건 이상**

### Cross Exchange · 게임 토큰 거래소

- 이중화된 트랜잭션 처리 로직을 분석하고 SDK에 어댑터를 주입하는 구조로 인터페이스 통합
- 모노레포에서 독립 프로젝트로 마이그레이션 주도
- Swagger 명세 기반 DTO·Entity·Repository 자동 생성 구조 구축
- 기존 기능을 유지하며 **전체 코드량 약 30% 절감**
- 마켓 설정을 S3에서 외부 관리해 신규 마켓 추가 시 코드 수정과 재배포 제거

### Cross STAKING · 토큰 스테이킹

- 사내 AI 에이전트가 만든 프로토타입을 Figma와 서비스 요구사항에 맞춰 재구현
- 운영 일정별 화면·기능 전환을 사전에 검증할 수 있는 날짜·시간 설정 기능 구축
- 프로토타입 전달 후 5일 안에 레이아웃, 지갑 연동, 주요 기능을 개선하여 기한 내 출시

### Cross Points · 포인트 서비스 (서비스 종료)

- EIP-1193 기반으로 지갑 설치 여부를 판별해 지갑 연결 과정을 3단계에서 2단계로 단축하고 연결 UX 개선
- 쿠키 기반 JWT 인증 체계를 설계하고, 미들웨어 프록시에서 토큰 추출·갱신·헤더 주입을 일괄 처리해 인증 API를 단일 진입점으로 통합
- PKCE 기반 Twitter OAuth 2.0 인증을 구현하고, iOS 인앱 브라우저에서 발생하던 인증 세션 유실을 딥링크 기반 콜백 리다이렉트로 해결

## [위메이드](https://www.wemade.com/kr) · 프론트엔드 개발

### Pnix Exchange · 오더북 기반 멀티마켓 게임 토큰 거래소

- 2인 팀에서 DEX의 초기 설계부터 출시 및 운영 유지보수까지 웹 프론트엔드 담당
- TradingView DataFeed에 과거 시세 API와 실시간 WebSocket을 연동한 가격 스트리밍 차트 구현
- 고빈도 오더북 데이터에 ref 기반 버퍼링과 배치 업데이트를 적용해 프레임 드롭 방지
- Page Visibility API로 이벤트 구독을 제어하여 백그라운드에서 누적된 메시지를 처리할 때 발생하던 프레임 드롭 개선
- 호가 단위의 React key를 설계해 동일 호가 내 수량 변경에만 애니메이션을 실행하고 불필요한 리렌더링 최소화
- 동일 프레임에 누적된 스타일 변경으로 CSS 전환이 무시되는 원인을 분석하고 rAF 기반 애니메이션으로 전환해 안정적인 상태 변경 구현
- `useDeferredValue`로 렌더링 우선순위를 분리해 고빈도 체결 중에도 탭 전환 응답성 유지
- 대규모 트래픽 봇 테스트에서도 안정적인 오더북 렌더링 유지
