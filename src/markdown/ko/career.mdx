# 직무경력

## 서재호 · 프론트엔드 엔지니어

고빈도 실시간 데이터와 Web3 트랜잭션 환경에서 운영 이슈를 스스로 정의하고 끝까지 해결하는 프론트엔드 엔지니어입니다. 약 4년간 블록체인 기반 웹 서비스와 WebView 어플리케이션을 개발하며 설계부터 출시와 운영까지 경험했습니다.

## 기술

- **언어** TypeScript, JavaScript, Python
- **프론트엔드** React, Next.js, Zustand, Redux Toolkit, TanStack Query
- **Web3** Wagmi, Ethers.js, Viem, WalletConnect, Reown AppKit
- **실시간 처리 및 시각화** WebSocket, TradingView, Canvas API, Rive
- **UI 및 스타일링** Tailwind CSS, Emotion, MUI, Framer Motion
- **도구 및 인프라** Jira, Confluence, Slack, Figma, GitHub Actions

### Cross Exchange · 게임 토큰 거래소

<div className="project-tech"><span>React</span><span>TypeScript</span><span>Zustand</span><span>Zod</span><span>Tailwind CSS</span><span>shadcn/ui</span><span>Monorepo</span></div>

- 이중화된 트랜잭션 처리 로직을 분석하고 SDK에 어댑터를 주입하는 구조로 인터페이스 통합
- 모노레포에서 독립 프로젝트로 마이그레이션 주도
- Feature-Sliced Design(FSD)을 전면 도입해 프로젝트를 app·pages·widgets·features·entities·shared 레이어로 분리하고, 기능 단위 응집도를 높여 팀 협업 시 파일 충돌 최소화
- Swagger 명세를 분석해 DTO·Entity·Repository 기본 코드를 자동 생성하는 구조를 구축하고, API 응답 변환을 Repository 계층에 캡슐화해 서버 스키마 변경이 UI 컴포넌트까지 전파되는 범위를 최소화
- 모바일·PC로 분리된 컴포넌트와 비즈니스 로직을 통합하고, 로컬·글로벌 상태의 책임을 재정의해 기존 기능을 유지하면서 코드량을 약 30% 절감
- 기존 환경 변수로 관리하던 마켓별 API·WebSocket 주소를 S3 기반 외부 설정으로 이전하여 신규 마켓 추가 시 코드 수정과 재배포 제거

- useDeferredValue로 렌더링 우선순위를 분리해 고빈도 체결 중에도 탭 전환 응답성 유지
- MUI 등 무거운 UI 프레임워크 의존성을 줄이기 위해 커스텀 훅 기반의 재사용 가능한 테이블 헤더 컴포넌트를 자체 설계하여 번들 크기를 최적화하고 스타일링 유연성 향상
