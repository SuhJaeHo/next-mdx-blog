# Chrome-like 그룹 탭 컴포넌트 패키지 배포

Chrome-like 그룹 탭 인터랙션과 리사이징 로직을 콘텐츠와 분리해 재사용 가능한 컴포넌트 패키지로 구성했습니다. Rollup 기반 빌드 환경을 구축하고 타입 선언과 스타일 결과물을 함께 배포하여 다른 프로젝트에서도 동일한 탭·패널 인터랙션을 사용할 수 있도록 <a className="npm-inline-link" href="https://www.npmjs.com/package/group-tabs-layout" target="_blank" rel="noreferrer">NPM</a>에 배포했습니다.

## Rollup을 선택한 이유

Rollup은 컴포넌트 라이브러리에 다음과 같은 장점이 있습니다.

1. 표준 ES Module과 CommonJS 결과물을 생성합니다.
2. 모듈 그래프의 정적 분석을 통해 트리 셰이킹을 수행합니다.
3. TypeScript, CommonJS 의존성, CSS, 코드 압축을 위한 명확한 플러그인 체계를 제공합니다.

트리 셰이킹만으로 모든 사용자의 번들이 항상 최소화되는 것은 아닙니다. ES Module 경계를 유지하고 불필요한 부수 효과를 피하며 패키지 메타데이터를 정확하게 선언해야 효과적으로 동작합니다.

## Rollup 플러그인 구성과 역할

<div className="code-explanation-list">
  <div><strong>@rollup/plugin-typescript</strong><span>TypeScript 컴파일러로 코드를 변환하고 진단 정보를 제공합니다. declaration을 활성화하면 타입 선언 파일도 생성할 수 있습니다.</span></div>
  <div><strong>@rollup/plugin-node-resolve</strong><span>Node 방식으로 패키지를 해석해 Rollup이 node_modules의 의존성을 찾도록 합니다.</span></div>
  <div><strong>@rollup/plugin-commonjs</strong><span>CommonJS 모듈을 Rollup이 분석할 수 있는 ES Module로 변환합니다.</span></div>
  <div><strong>Peer dependency와 external</strong><span>React와 React DOM은 peer dependency로 선언해야 하며, 사용하는 어플리케이션이 런타임을 제공하므로 React가 중복 번들링되는 것을 방지할 수 있습니다. peer dependency 선언만으로 Rollup의 제외가 보장되지는 않으므로 빌드 설정에서도 external로 지정해야 합니다.</span></div>
  <div><strong>rollup-plugin-postcss</strong><span>가져온 스타일을 처리합니다. 패키지 계약에 따라 JavaScript에서 CSS를 주입하거나 사용자가 직접 가져오는 별도 파일로 추출할 수 있습니다.</span></div>
</div>

## Rollup 설정

```js
import commonjs from "@rollup/plugin-commonjs";
import resolve from "@rollup/plugin-node-resolve";
import terser from "@rollup/plugin-terser";
import typescript from "@rollup/plugin-typescript";
import postcss from "rollup-plugin-postcss";

export default {
  input: "src/index.ts",
  external: ["react", "react-dom"],
  output: [
    { file: "dist/index.js", format: "esm", sourcemap: true },
    { file: "dist/index.cjs", format: "cjs", exports: "named", sourcemap: true },
  ],
  plugins: [
    resolve(),
    commonjs(),
    typescript({ tsconfig: "./tsconfig.build.json" }),
    postcss({ extract: "styles.css", minimize: true }),
    terser(),
  ],
};
```

## TypeScript 빌드 설정

```json
{
  "compilerOptions": {
    "target": "ES2019",
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "lib": ["DOM", "ES2020"],
    "jsx": "react-jsx",
    "declaration": true,
    "declarationDir": "dist/types",
    "emitDeclarationOnly": false,
    "strict": true,
    "skipLibCheck": true
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "dist"]
}
```

</div>
