# Group Tabs Layout

`group-tabs-layout`은 JSON 데이터와 Context API를 연결하고 Next.js 동적 라우팅으로 MDX 파일을 렌더링하는 상태 기반 UI 라이브러리입니다.

## 설치

```bash
pnpm add group-tabs-layout
```

## 사용 방법

```tsx
"use client";

import Board from "group-tabs-layout";

export default function GroupTabsLayout({ data, mdxSources }) {
  return (
    <Board.Root
      boardData={data}
      customConstants={{
        TAB_SIZES: { WIDTH: 100, HEIGHT: 50 },
        GROUP_MINIMUM_SIZE: { WIDTH: 200, HEIGHT: 300 },
      }}
    >
      <Board.Nav>
        <Board.NavList />
      </Board.Nav>
      <Board.Panel>
        <Board.GroupIndicate />
        <Board.Groups>
          <Board.Group mdxSources={mdxSources}>
            <Board.GroupHeader>
              <Board.Tab />
              <Board.TabIndicate />
            </Board.GroupHeader>
            <Board.TabContent>
              <CustomMDX />
            </Board.TabContent>
          </Board.Group>
        </Board.Groups>
      </Board.Panel>
    </Board.Root>
  );
}
```

`boardData`에는 현재 페이지, 패널, 탭의 관계와 각 패널의 위치·크기를 저장합니다. 각 탭의 `contentFile`은 렌더링할 MDX 파일을 가리킵니다.

## API

### Context API 연동

패키지는 `boardData`를 상태로 관리하고 Context API를 통해 Board의 하위 컴포넌트에 공유합니다.

### MDX 연동

- JSON의 탭 객체에 `contentFile` 속성을 추가합니다.
- `contentFile`에는 렌더링할 MDX 파일 이름을 지정합니다.
- `MDXRemote`와 같은 사용자 정의 컴포넌트로 문서를 동적으로 렌더링합니다.
- 사용자 정의 MDX 컴포넌트에 `mdxContent`와 `groupId`를 전달합니다.

### `Board.Root`

- `boardData`: 레이아웃을 초기화하는 데이터입니다.
- `customConstants`: 탭 크기와 패널 최소 크기 등의 상수를 설정합니다.

### 스타일링

패키지는 Tailwind CSS를 사용합니다. 각 Board 컴포넌트에 className을 전달해 원하는 스타일로 변경할 수 있습니다.
