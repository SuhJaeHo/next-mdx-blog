# 서비스의 완성도를 높이는 프론트엔드 엔지니어

약 4년간 프론트엔드 개발자로서 서비스 초기 설계부터 출시, 운영, 성능 개선과 레거시 리팩토링까지 경험했습니다. 복잡한 문제를 가능한 단순하고 실용적인 방식으로 해결하는 것을 중요하게 생각하며, 사용자가 체감할 수 있는 안정성과 완성도를 높이는 데 집중해왔습니다. 또한 좋은 결과는 혼자가 아닌 팀에서 만들어진다고 생각하며, 동료에 대한 존중과 배려를 바탕으로 협업하고 있습니다.

## 경험을 통해 확신한 개발자의 길

한국기술교육대학교에서 응용화학공학을 전공하며 진로에 대해 많은 고민을 했습니다. 공무원 시험을 준비하고 전공 공부를 이어가며 제가 정말 하고 싶은 일이 무엇인지 돌아보던 중, 1학년 때 C언어 수업을 즐겁게 들었던 경험을 떠올려 개발자라는 직업에 관심을 갖게 되었습니다.

개발이 제 적성에 맞는지 직접 확인하기 위해 휴학 후 Java 기반 웹 개발 과정을 수강했습니다. 문제를 분석하고 해결해 실제 결과물을 만들어내는 과정에서 큰 성취감을 느꼈고, 개발자로 진로를 정하게 되었습니다.

졸업 후에는 바닐라코딩 부트캠프에서 프론트엔드를 중심으로 한 풀스택 과정을 이수했으며, 이후 위메이드에서 프론트엔드 개발자로 커리어를 시작했습니다. 현재도 새로운 기술을 배우고 더 나은 사용자 경험과 서비스 품질을 만들기 위해 고민하는 과정에서 즐거움을 느끼며 성장하고 있습니다.

## 성능과 사용자 경험을 고려한 개발

위메이드에서 오더북 기반 게임 토큰 거래소의 웹 프론트엔드 개발에 참여했습니다. 소규모 팀에서 초기 설계부터 출시와 운영까지 경험했으며, 인원이 축소된 상황에서도 기존 구조와 거래 로직을 빠르게 파악해 서비스를 안정적으로 이어갔습니다.

실시간 시세와 오더북처럼 대량의 데이터가 지속적으로 유입되는 화면의 성능 개선을 담당했습니다. 실시간 데이터를 버퍼링하고 일정 주기로 일괄 반영해 불필요한 렌더링을 줄였으며, 렌더링 우선순위를 조정해 대량의 데이터가 유입되는 상황에서도 안정적인 사용자 경험을 유지할 수 있도록 했습니다.

어떻게 하면 요구되는 기능을 구현하면서 사용자 경험을 극대화 할 수 있을지 고민하며 일정 안에 제품을 구현하는 데서 그치지 않고, 출시 이후에도 안정적으로 운영될 수 있도록 완성도를 높이는 것을 목표로 합니다.

## 앞으로의 목표

앞으로는 프론트엔드 역량을 더욱 깊게 다지는 동시에 백엔드와 인프라까지 이해 범위를 넓혀, 서비스 전체의 데이터 흐름과 구조를 함께 고려할 수 있는 소프트웨어 엔지니어로 성장하고 싶습니다.

특정 기술이나 도메인에 머무르기보다 다양한 서비스를 경험하며 요구사항과 사용자의 문제를 빠르게 이해하고, 상황에 맞는 기술적 해결책을 제시할 수 있는 역량을 갖추고자 합니다. 또한 주어진 기능을 구현하는 데 그치지 않고 일정과 품질의 균형을 고려해 팀이 안정적으로 결과물을 완성하는 데 기여하는 개발자가 되고 싶습니다.

AI 도구 역시 단순한 코드 생성 수단이 아니라 요구사항 분석, 반복 작업 자동화, 테스트와 코드 검토 등 개발 과정 전반에 활용해 생산성과 결과물의 완성도를 높이고자 합니다.

장기적으로는 프론트엔드와 백엔드의 경계를 넘어 기술적 의사결정에 참여하며, 사용자가 만족할 수 있는 안정적이고 편리한 서비스를 만드는 소프트웨어 엔지니어로 성장하는 것이 목표입니다.
