# 포트폴리오를 만든 과정

이 사이트는 정해진 템플릿에 내용을 채운 포트폴리오가 아닙니다. Chrome과 유사한 탭 경험에서 착안해, 문서를 자유롭게 배치하고 비교할 수 있는 **인터랙티브 워크스페이스**를 직접 설계했습니다. 화면 전체의 레이아웃과 인터랙션을 담당하는 이 핵심 컴포넌트를 프로젝트 내부에서 **Board**라고 부릅니다.

> 완성된 결과물뿐 아니라 브라우저 인터랙션을 설계하고, 재사용 가능한 구조로 구현해 배포한 뒤 개선해 온 과정까지 함께 보여주는 프로젝트입니다.

## 직접 만든 것

- **Chrome형 탭 인터랙션** — 탭을 재정렬하고, 다른 패널로 분리하거나 다시 병합하는 흐름을 직접 구현
- **Vanilla DOM API 기반 레이아웃 엔진** — 외부 드래그 라이브러리 없이 8방향 리사이즈, 그룹 이동, 탭 리오더링·분리·병합 구현
- **경계 기반 화면 배치** — 패널 또는 탭을 화면 가장자리에 놓으면 절반 크기로 맞추고, 전체 화면과 이전 상태 복원까지 처리
- **재사용 가능한 패키지** — 이 사이트 밖에서도 사용할 수 있도록 Board 기반을 분리해 NPM으로 배포
- **MDX 콘텐츠 시스템** — UI 로직과 문서를 분리해 Board를 수정하지 않고도 새로운 글을 추가
- **다국어 포트폴리오** — 자기소개, 직무경력, 포트폴리오 구현 기록을 영어·한국어·일본어로 제공

## 이 형식을 선택한 이유

자기소개서, 직무경력, 구현 기록은 방문 목적에 따라 읽는 순서와 중요도가 다릅니다. 한 방향으로 스크롤하는 구성보다 필요한 문서를 직접 열고 배치하는 방식이 이 포트폴리오에 더 적합하다고 판단했습니다.

각 문서는 독립된 탭으로 열립니다. 자기소개서와 직무경력을 나란히 비교하거나, 관심 있는 구현 기록만 별도 패널로 분리해 살펴볼 수 있습니다. Board는 이러한 탐색 방식을 가능하게 하는 **화면 레이아웃이자 인터랙션 엔진**입니다.

## 구성 요소의 연결

| 계층 | 역할 |
| --- | --- |
| Board | 전체 화면 레이아웃과 탭·패널의 이동, 8방향 크기 조절, 분리, 병합, 포커스 관리 |
| NPM package | Chrome형 탭·패널 인터랙션을 다른 프로젝트에서도 재사용할 수 있도록 제공 |
| MDX | 경력 문서와 기술 글을 UI 코드와 독립적으로 관리 |
| Locale content | Board 상태를 초기화하지 않고 영어·한국어·일본어 본문 전환 |
| Next.js | 경로를 사전 렌더링하고 실제로 운영되는 제품 형태로 전달 |

## 문서 구성

1. **소개**에서 이 포트폴리오를 만든 이유와 보여주려는 역량을 설명합니다.
2. **Board 패키지**에서 재사용 가능한 UI를 패키징하고 배포한 과정을 다룹니다.
3. **MDX 통합**에서 문서와 탭을 연결한 구조를 설명합니다.
4. **문서화**에서 다른 개발자가 패키지를 설치하고 사용하는 방법을 보여줍니다.
