# 이 포트폴리오를 만든 과정

이 사이트는 정해진 템플릿에 내용을 채운 포트폴리오가 아닙니다. Board 인터페이스를 직접 설계하고 구현했으며, 재사용 가능한 기반을 NPM 패키지로 배포한 뒤 MDX와 결합해 경력과 함께 계속 확장할 수 있는 포트폴리오로 만들었습니다.

> 이 포트폴리오 자체가 문제를 정의하고, 인터랙션을 설계하고, 재사용 가능한 구조로 구현하고, 출시한 뒤 실제로 사용하며 개선하는 과정을 보여주는 프로젝트입니다.

## 직접 만든 것

- **인터랙티브 Board UI** — 브라우저 탭과 tiling window manager에서 영감을 받은 이동·크기 조절 가능한 패널
- **복합 인터랙션** — 탭 재정렬, 패널 분리·병합, 가장자리 snap, fullscreen과 원래 상태 복원
- **재사용 가능한 패키지** — 이 사이트 밖에서도 사용할 수 있도록 Board 기반을 분리해 NPM으로 배포
- **MDX 콘텐츠 시스템** — UI 로직과 문서를 분리해 Board를 수정하지 않고도 새로운 글을 추가
- **다국어 포트폴리오** — 자기소개, 직무경력, 기술 학습 기록을 영어·한국어·일본어로 제공

## 이 형식을 선택한 이유

일반적인 포트폴리오는 모든 방문자에게 고정된 순서로 정보를 보여줍니다. 저는 여러 맥락을 함께 살펴보고, 정보를 재배치하고, 지금 중요한 부분에 집중하는 제 작업 방식을 더 잘 보여주는 형식을 만들고 싶었습니다.

Board는 각 문서를 하나의 탭으로 다룹니다. 채용담당자는 자기소개서와 직무경력을 나란히 열어볼 수 있고, 개발자는 이 포트폴리오 자체를 구현한 기술 기록을 확인할 수 있습니다. 같은 인터페이스에 현재는 경력 문서를 담고, 앞으로 프로젝트 회고와 기술 학습 기록을 계속 추가할 수 있습니다.

## 구성 요소의 연결

| 계층 | 역할 |
| --- | --- |
| Board | 패널, 탭, drag, resize, 분리, 병합, focus 관리 |
| NPM package | 이 포트폴리오 밖에서도 interaction model을 재사용할 수 있게 제공 |
| MDX | 경력 문서와 기술 글을 UI 코드와 독립적으로 관리 |
| Locale content | Board 상태를 초기화하지 않고 영어·한국어·일본어 본문 전환 |
| Next.js | 경로를 사전 렌더링하고 실제로 운영되는 제품 형태로 전달 |

## 이 카테고리의 이야기

1. **소개**에서 이 포트폴리오를 만든 이유와 보여주려는 역량을 설명합니다.
2. **Board 패키지**에서 재사용 가능한 UI를 패키징하고 배포한 과정을 다룹니다.
3. **MDX 통합**에서 문서와 탭을 연결한 구조를 설명합니다.
4. **문서화**에서 다른 개발자가 패키지를 설치하고 사용하는 방법을 보여줍니다.

이 포트폴리오는 채용을 위한 소개 자료이면서 제가 공부하고 만든 것을 계속 기록하는 공간입니다. 따라서 이 형식은 콘텐츠를 꾸미는 장식이 아니라, 제가 보여드리고 싶은 프로젝트 중 하나입니다.
