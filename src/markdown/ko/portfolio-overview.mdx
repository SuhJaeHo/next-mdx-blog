# Chrome-like 그룹 탭

Chrome과 유사한 그룹 탭 경험에서 착안해, 문서를 자유롭게 배치하고 비교할 수 있는 인터랙티브 워크스페이스를 직접 설계했습니다.

## 기능 구현 목록

<ul className="overview-feature-list">
  <li><strong>Chrome-like 그룹 탭 인터랙션</strong><span>탭을 재정렬하고, 다른 패널로 분리하거나 다시 병합하는 인터랙션을 Vanilla DOM API로 구현</span></li>
  <li><strong>리사이징 구현</strong><span>탭 또는 그룹을 패널 외부로 드래그해서 놓으면 해당 영역의 절반 크기에 맞춰 리사이징되며, 그룹 헤더를 더블클릭하면 전체화면 또는 이전 사이즈로 리사이징되도록 구현</span></li>
  <li><strong>NPM 패키지화</strong><span>Chrome-like 탭 리사이징 UI를 독립 패키지로 분리해 NPM에 배포</span></li>
  <li><strong>MDX 기반 콘텐츠 렌더링</strong><span>next-mdx-remote를 활용해 MDX 콘텐츠를 직렬화하고, GFM 및 코드 하이라이팅을 적용해 탭별 문서 콘텐츠를 렌더링</span></li>
</ul>

## 포트폴리오 만든 계기

Chrome 그룹 탭 인터랙션을 활용하여 자유롭게 작성한 글들의 목록을 분리 및 병합하거나 동시에 여러 글을 볼 수 있는 형태로 제공할 수 있으면 좋을 것 같다고 판단하였습니다. 이를 활용하여 저만의 포트폴리오이자 추후에는 학습한 내용을 기록 및 정리하는 블로그 포맷으로 활용하고자 합니다.
