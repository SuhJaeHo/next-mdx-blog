# Chrome-likeグループタブコンポーネントパッケージの公開

Chrome-likeグループタブインタラクションとリサイズロジックをコンテンツから分離し、再利用可能なコンポーネントパッケージとして構成しました。Rollupベースのビルド環境を整備し、型宣言とスタイル出力を含めて<a className="npm-inline-link" href="https://www.npmjs.com/package/group-tabs-layout" target="_blank" rel="noreferrer">NPM</a>へ公開することで、同じタブ・パネルインタラクションを他のプロジェクトでも利用できるようにしました。

## Rollupを選んだ理由

Rollupはコンポーネントライブラリに次の利点を提供します。

1. 標準的なES ModuleとCommonJSの出力を生成します。
2. モジュールグラフの静的解析によってツリーシェイキングを行います。
3. TypeScript、CommonJS依存関係、CSS、圧縮のための明確なプラグイン構成を提供します。

ツリーシェイキングだけで、すべての利用者に最小のバンドルが保証されるわけではありません。ES Moduleの境界を保ち、不要な副作用を避け、パッケージのメタデータを正しく宣言する必要があります。

## Rollupプラグイン構成と役割

<div className="code-explanation-list">
  <div><strong>@rollup/plugin-typescript</strong><span>TypeScriptコンパイラでコードを変換し、診断情報を出力します。declarationを有効にすると型宣言ファイルも生成できます。</span></div>
  <div><strong>@rollup/plugin-node-resolve</strong><span>Node方式でパッケージを解決し、Rollupがnode_modules内の依存関係を見つけられるようにします。</span></div>
  <div><strong>@rollup/plugin-commonjs</strong><span>CommonJSモジュールを、Rollupが解析できるES Moduleへ変換します。</span></div>
  <div><strong>Peer dependencyとexternal</strong><span>ReactとReact DOMはpeer dependencyとして宣言し、利用側のアプリケーションがランタイムを提供するため、Reactの二重バンドルを防げます。peer dependencyの宣言だけではRollupからの除外は保証されないため、ビルド設定でもexternalに指定します。</span></div>
  <div><strong>rollup-plugin-postcss</strong><span>importされたスタイルを処理します。JavaScriptからCSSを注入する方法と、利用者が明示的にimportする別ファイルへ抽出する方法を選べます。</span></div>
</div>

## Rollup設定

```js
import commonjs from "@rollup/plugin-commonjs";
import resolve from "@rollup/plugin-node-resolve";
import terser from "@rollup/plugin-terser";
import typescript from "@rollup/plugin-typescript";
import postcss from "rollup-plugin-postcss";

export default {
  input: "src/index.ts",
  external: ["react", "react-dom"],
  output: [
    { file: "dist/index.js", format: "esm", sourcemap: true },
    { file: "dist/index.cjs", format: "cjs", exports: "named", sourcemap: true },
  ],
  plugins: [
    resolve(),
    commonjs(),
    typescript({ tsconfig: "./tsconfig.build.json" }),
    postcss({ extract: "styles.css", minimize: true }),
    terser(),
  ],
};
```

## TypeScriptビルド設定

```json
{
  "compilerOptions": {
    "target": "ES2019",
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "lib": ["DOM", "ES2020"],
    "jsx": "react-jsx",
    "declaration": true,
    "declarationDir": "dist/types",
    "emitDeclarationOnly": false,
    "strict": true,
    "skipLibCheck": true
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "dist"]
}
```

```json
{

  "module": "./dist/index.js",
  "types": "./dist/types/index.d.ts",

  },

  "peerDependencies": { "react": ">=18", "react-dom": ">=18" },
  "sideEffects": ["**/*.css"]
}
```
