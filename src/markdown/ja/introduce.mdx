# サービスの完成度を高めるフロントエンドエンジニア

約4年間、フロントエンドエンジニアとしてサービスの初期設計からリリース、運用、性能改善、レガシーリファクタリングまで経験してきました。複雑な問題をできるだけシンプルで実用的な方法で解決することを大切にし、ユーザーが体感できる安定性と完成度を高めることに注力してきました。また、良い成果は一人ではなくチームで作られるものだと考え、同僚への尊重と配慮をもとに協業しています。

## 経験を通じて確信したエンジニアの道

韓国技術教育大学で応用化学工学を専攻しながら、進路について多く悩みました。公務員試験の準備と専攻の勉強を続けながら、自分が本当にやりたいことは何かを振り返る中で、1年生のときにC言語の授業を楽しく受けた経験を思い出し、開発者という職業に関心を持つようになりました。

開発が自分の適性に合うかを直接確認するため、休学後にJavaベースのWeb開発課程を受講しました。問題を分析し、解決して実際に動く成果物を作る過程で大きな達成感を感じ、開発者として進路を決めました。

卒業後はVanilla Coding Bootcampでフロントエンド中心のフルスタック課程を修了し、その後Wemadeでフロントエンド開発者としてキャリアを始めました。現在も新しい技術を学び、より良いユーザー体験とサービス品質を作るために考える過程に楽しさを感じながら成長しています。

## 性能とユーザー体験を考慮した開発

Wemadeでは、オーダーブックベースのゲームトークン取引所のWebフロントエンド開発に参加しました。少人数チームで初期設計からリリース、運用まで経験し、メンバーが減った状況でも既存の構造と取引ロジックを素早く把握してサービスを安定的に継続しました。

リアルタイム価格やオーダーブックのように大量のデータが継続的に流入する画面の性能改善を担当しました。リアルタイムデータをバッファリングし、一定周期でまとめて反映することで不要なレンダリングを減らし、レンダリング優先度を調整して、大量のデータが流入する状況でも安定したユーザー体験を維持できるようにしました。

要求される機能を実装しながら、どうすればユーザー体験を最大化できるかを考えています。決められた期間内にプロダクトを実装するだけでなく、リリース後も安定して運用できるように完成度を高めることを目標としています。

## 今後の目標

今後はフロントエンドの力をさらに深めると同時に、バックエンドとインフラまで理解の範囲を広げ、サービス全体のデータフローと構造を一緒に考えられるソフトウェアエンジニアへ成長したいです。

特定の技術やドメインにとどまるのではなく、多様なサービスを経験し、要求事項とユーザーの問題を素早く理解して、状況に合った技術的解決策を提示できる力を身につけたいと考えています。また、与えられた機能を実装するだけでなく、スケジュールと品質のバランスを考慮し、チームが安定して成果物を完成させることに貢献できる開発者になりたいです。

AIツールも単なるコード生成手段ではなく、要求事項分析、反復作業の自動化、テスト、コードレビューなど開発プロセス全体で活用し、生産性と成果物の完成度を高めたいと考えています。

長期的には、フロントエンドとバックエンドの境界を越えて技術的な意思決定に参加し、ユーザーが満足できる安定した便利なサービスを作るソフトウェアエンジニアへ成長することが目標です。
