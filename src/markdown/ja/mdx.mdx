# MDX

MDXはJSX構文を使えるように拡張されたMarkdownです。文章、Markdown構造、JavaScript式、コンポーネントを同じドキュメント処理パイプラインで扱えます。

## コンパイルパイプライン

<div className="code-explanation-list">
  <div><strong>MarkdownとMDX構文を解析してAbstract Syntax Treeへ変換</strong><span>MarkdownノードとMDX固有ノードをMarkdown抽象構文木として表現します。</span></div>
  <div><strong>remarkプラグインを実行</strong><span>remarkプラグインはmdastを検査・変換します。remark-gfmは表やタスクリストなどGitHub Flavored Markdownの機能を追加します。</span></div>
  <div><strong>Markdown ASTをHTML ASTへ変換</strong><span>Markdown ASTをHTML ASTへ変換し、MDXのJSXと式は後続のコンパイル段階で処理できるよう保持します。</span></div>
  <div><strong>rehypeプラグインを実行</strong><span>rehypeプラグインはhastを検査・変換します。このポートフォリオではrehype-prism-plusでコードブロックにシンタックスハイライト情報を付けます。</span></div>
</div>

## MDXレンダリング過程

```ts
import { serialize } from "next-mdx-remote/serialize";
import rehypePrism from "rehype-prism-plus";
import remarkGfm from "remark-gfm";

const source = await serialize(fileContent, {
  mdxOptions: {
    remarkPlugins: [remarkGfm],
    rehypePlugins: [rehypePrism],
    format: "mdx",
  },
});
```

<div className="code-explanation-list">
  <div><strong>MDXファイルのシリアライズ</strong><span>静的生成の過程でMDXファイルを読み、serializeでシリアライズします。</span></div>
</div>

```tsx
import { MDXRemote } from "next-mdx-remote";

const components = { pre: CodeBlock };

export function CustomMDX({ source }) {
  return <MDXRemote {...source} components={components} />;
}
```

<div className="code-explanation-list">
  <div><strong>React要素のレンダリング</strong><span>シリアライズした結果をMDXRemoteへ渡し、React要素としてレンダリングします。</span></div>
</div>
