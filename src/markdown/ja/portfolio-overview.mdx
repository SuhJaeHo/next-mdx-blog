# このポートフォリオの作り方

このサイトは、既成テンプレートに内容を入れただけのポートフォリオではありません。Boardインターフェースを自ら設計・実装し、再利用可能な基盤をNPMパッケージとして公開したうえで、MDXと組み合わせ、キャリアとともに成長し続けるポートフォリオにしました。

> このポートフォリオ自体が、課題を定義し、インタラクションを設計し、再利用可能な構造として実装し、リリース後も実際に使いながら改善する過程を示すプロジェクトです。

## 実装したもの

- **インタラクティブBoard UI** — ブラウザのタブとtiling window managerから着想した、移動・サイズ変更可能なパネル
- **複合インタラクション** — タブの並べ替え、パネルの分割・結合、edge snap、fullscreenと元の状態への復元
- **再利用可能なパッケージ** — このサイト以外でも使えるようBoard基盤を分離し、NPMで公開
- **MDXコンテンツシステム** — UIロジックと文書を分離し、Boardを変更せずに新しい記事を追加
- **多言語ポートフォリオ** — 自己紹介、職務経歴、技術学習ノートを英語・韓国語・日本語で提供

## この形式を選んだ理由

一般的なポートフォリオは、すべての訪問者に固定された順序で情報を見せます。私は、複数の文脈を同時に確認し、情報を並べ替え、今重要な部分に集中する自分の働き方を、よりよく表す形式を作りたいと考えました。

Boardは各文書を1つのタブとして扱います。採用担当者は自己紹介書と職務経歴を並べて確認でき、エンジニアはこのポートフォリオ自体の実装記録を開けます。同じインターフェースに、現在はキャリア文書を、今後はプロジェクトの振り返りや技術学習ノートを継続的に追加できます。

## 構成要素のつながり

| レイヤー | 役割 |
| --- | --- |
| Board | パネル、タブ、drag、resize、分割、結合、focusを管理 |
| NPM package | ポートフォリオ外でもinteraction modelを再利用可能にする |
| MDX | キャリア文書と技術記事をUIコードから独立して管理 |
| Locale content | Board状態を初期化せず英語・韓国語・日本語を切り替え |
| Next.js | 各ルートを事前レンダリングし、実際に運用するプロダクトとして配信 |

## このセクションのストーリー

1. **概要**では、このポートフォリオを作った理由と示したい能力を説明します。
2. **Boardパッケージ**では、再利用可能なUIをパッケージ化して公開した過程を扱います。
3. **MDX統合**では、文書とタブを接続する構造を説明します。
4. **ドキュメント**では、他の開発者がパッケージを導入して利用する方法を示します。

このポートフォリオは採用のための自己紹介資料であると同時に、学びと制作物を継続して記録する場所です。そのため、この形式はコンテンツを飾るものではなく、私自身が紹介したいプロジェクトの一つです。
