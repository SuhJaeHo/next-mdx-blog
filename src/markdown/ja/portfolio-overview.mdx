# Chrome-likeグループタブ

Chromeのようなグループタブ体験から着想を得て、文書を自由に配置・比較できるインタラクティブワークスペースを設計しました。

## 機能実装一覧

<ul className="overview-feature-list">
  <li><strong>Chrome-likeグループタブインタラクション</strong><span>タブの並べ替え、別パネルへの分割、再結合のインタラクションをVanilla DOM APIで実装</span></li>
  <li><strong>リサイズ実装</strong><span>タブまたはグループをパネル外へドラッグしてドロップすると対象領域の半分のサイズにリサイズされ、グループヘッダーをダブルクリックすると全画面または以前のサイズへ切り替わるように実装</span></li>
  <li><strong>NPMパッケージ化</strong><span>Chrome-likeタブリサイズUIを独立したパッケージとして分離し、NPMで公開</span></li>
  <li><strong>MDXベースのコンテンツレンダリング</strong><span>next-mdx-remoteを活用してMDXコンテンツをシリアライズし、GFMとコードハイライトを適用してタブごとの文書コンテンツをレンダリング</span></li>
</ul>

## ポートフォリオを作ったきっかけ

Chromeのグループタブインタラクションを活用し、自由に書いた記事の一覧を分離・結合したり、複数の記事を同時に閲覧できる形式で提供できると良いと考えました。これを自分だけのポートフォリオとして活用し、今後は学習した内容を記録・整理するブログフォーマットとしても使っていきたいと考えています。
