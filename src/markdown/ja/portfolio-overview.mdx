# このポートフォリオの作り方

このサイトは、既成テンプレートに内容を入れただけのポートフォリオではありません。Chromeのようなタブ体験から着想を得て、文書を自由に配置・比較できる**インタラクティブワークスペース**を設計しました。画面全体のレイアウトとインタラクションを担う中核コンポーネントを、プロジェクト内では**Board**と呼んでいます。

> 完成した画面だけでなく、ブラウザインタラクションを設計し、再利用可能な基盤として実装・公開した後、継続して改善してきた過程まで示すプロジェクトです。

## 実装したもの

- **Chrome型タブインタラクション** — タブの並べ替え、独立したパネルへの分割、再結合までを直接実装
- **Vanilla DOM APIベースのレイアウトエンジン** — 外部ドラッグライブラリを使わず、8方向リサイズ、グループ移動、タブの並べ替え・分割・結合を実装
- **境界を利用した画面配置** — パネルやタブを画面端に置くと半分の領域にスナップし、全画面表示と以前の状態への復元にも対応
- **再利用可能なパッケージ** — このサイト以外でも使えるようBoard基盤を分離し、NPMで公開
- **MDXコンテンツシステム** — UIロジックと文書を分離し、Boardを変更せずに新しい記事を追加
- **多言語ポートフォリオ** — 自己紹介、職務経歴、ポートフォリオ実装記録を英語・韓国語・日本語で提供

## この形式を選んだ理由

自己紹介書、職務経歴、実装記録は、訪問目的によって読む順序と重要度が異なります。一方向にスクロールする構成より、必要な文書を直接開いて配置できる形式が、このポートフォリオには適していると判断しました。

各文書は独立したタブとして開きます。自己紹介書と職務経歴を並べて比較したり、関心のある実装記録だけを別パネルに分けて確認したりできます。Boardは、この閲覧方法を実現する**画面レイアウト兼インタラクションエンジン**です。

## 構成要素のつながり

| レイヤー | 役割 |
| --- | --- |
| Board | 画面全体のレイアウト、タブ・パネル移動、8方向リサイズ、分割、結合、フォーカスを管理 |
| NPM package | Chrome型タブ・パネルのインタラクションを他のプロジェクトでも再利用可能にする |
| MDX | キャリア文書と技術記事をUIコードから独立して管理 |
| Locale content | Board状態を初期化せず英語・韓国語・日本語を切り替え |
| Next.js | 各ルートを事前レンダリングし、実際に運用するプロダクトとして配信 |

## 文書構成

1. **概要**では、このポートフォリオを作った理由と示したい能力を説明します。
2. **Boardパッケージ**では、再利用可能なUIをパッケージ化して公開した過程を扱います。
3. **MDX統合**では、文書とタブを接続する構造を説明します。
4. **ドキュメント**では、他の開発者がパッケージを導入して利用する方法を示します。
