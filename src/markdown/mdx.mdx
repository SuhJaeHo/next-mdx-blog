# MDX

MDX is Markdown extended with JSX syntax. It allows prose, Markdown structures, JavaScript expressions, and components to participate in the same document pipeline.

## Compilation Pipeline

<div className="code-explanation-list">
  <div><strong>Parse Markdown and MDX syntax into an Abstract Syntax Tree</strong><span>Markdown nodes and MDX-specific nodes are represented in a Markdown abstract syntax tree.</span></div>
  <div><strong>Run remark plugins</strong><span>Remark plugins inspect or transform mdast. remark-gfm adds support for GitHub Flavored Markdown features such as tables and task lists.</span></div>
  <div><strong>Convert Markdown AST to HTML AST</strong><span>The Markdown AST is converted into an HTML AST, while MDX JSX and expressions are preserved so they can be handled during the later compilation step.</span></div>
  <div><strong>Run rehype plugins</strong><span>Rehype plugins inspect or transform hast. This portfolio uses rehype-prism-plus to annotate code blocks for syntax highlighting.</span></div>
</div>

## MDX Rendering Flow

```ts
import { serialize } from "next-mdx-remote/serialize";
import rehypePrism from "rehype-prism-plus";
import remarkGfm from "remark-gfm";

const source = await serialize(fileContent, {
  mdxOptions: {
    remarkPlugins: [remarkGfm],
    rehypePlugins: [rehypePrism],
    format: "mdx",
  },
});
```

<div className="code-explanation-list">
  <div><strong>Serialize MDX files</strong><span>During static generation, the server reads MDX files and serializes them with serialize.</span></div>
</div>

```tsx
import { MDXRemote } from "next-mdx-remote";

const components = {
  pre: CodeBlock,
};

export function CustomMDX({ source }) {
  return <MDXRemote {...source} components={components} />;
}
```
